💡 詞意推斷：上文下理推算策略秘笈

1. 什麼是「上文下理」？

文章中的詞語不是孤立存在的！「上文」指目標詞語前面的句子，「下理 (下文)」指目標詞語後面的句子。

2. 三大推論偵探招式：

  • 因果線索：看看前文是否寫出了原因，導致後面出現這個詞語的結果。
  • 對比線索：尋找「雖然……但是……」、「反而」等轉折詞，推算相反意思。
  • 解釋與舉例線索：後文往往會對前面的難懂詞語進行詳細動作描述或補充解釋。

3. 實戰示範：

「小明第一次在全校面前演講，緊張得忐忑不安，連手都在發抖。」

🟢 上文線索：「第一次全校演講」、「緊張」

🟡 下文線索：「手都在發抖」

💡 推論結果：由「緊張」與「手發抖」，可知「忐忑不安」是指心裡七上八下、非常不安恐懼。

🛠 GitHub Pages 無法上傳龍虎榜常見原因與解法：

  1. Firestore Rules (安全規則) 未開放：
    請至 Firebase Console -> Firestore Database -> Rules，將規則修改為： 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  2. 未啟用 Firestore Database：
    請確認已在 Firebase 後台點擊「建立資料庫 (Create Database)」。
  3. 離線與備份機制：
    即使 Firebase 未成功連接，遊戲已自動切換為 LocalStorage 本地備份模式，分數不會遺失且遊戲絕不卡死！
